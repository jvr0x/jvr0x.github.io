Voxel Bridge Challenge

One prompt, several local models — each had to build the same self-contained Three.js world.

The Challenge

Every model below received the exact same prompt: build a single self-contained HTML file — no external files, no server — with Three.js voxels that look good (soft rounded edges, ambient occlusion, warm rim lighting, smooth block animations). The scene: a dark world, an orbiting camera, and a blue river between two banks. Four buttons drive it — Build Bridge (a two-block-wide arch of exactly forty blocks in four colors), Earthquake (remove the two central supports, auto-rebuild from the remaining thirty-eight), Widen River (stretch the span from ten to fourteen units with the same blocks), and Reset. A live HUD shows block count and river width; a reasoning log narrates every step.

The prompt also requires each model to name its output folder after itself and stamp a Model: … badge under the page title — that's how you can tell who built what.
